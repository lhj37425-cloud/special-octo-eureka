# 独立后台验收记录（第三分支）

分支：`第三分支-独立后台`。本记录只依据隔离临时数据的自动验证和当前代码；不代表已完成云端部署或人工视觉验收。

| PRD 验收项 | 当前结论 | 证据 / 说明 |
| --- | --- | --- |
| 管理员初始化、登录、退出、会话与重置 | 已验证 | 带盐 scrypt 哈希、可撤销会话、30 分钟空闲与 8 小时最长时限；`验证真实后台.cjs`、`验证后台接口.cjs`。 |
| 未登录接口与草稿保护、CSRF、登录冷却 | 已验证 | 未授权、CSRF 拦截及连续错误登录冷却由 HTTP 验证覆盖。 |

| 中文、英文、越南文隔离 | 已验证核心规则 | 未录入英文时不会显示中文内容；每种语言拥有独立发布内容与媒体槽位。 |
