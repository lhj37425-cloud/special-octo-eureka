## 1. 背景与目标

现有项目具有本地内容管理页面和上传能力，但没有正式管理员登录及服务端权限保护。此次采用方案 A：复用现有网站业务与内容数据，重新建立使用独立网址的正式管理员后台；先在本机完成，再整体部署到云端。前台与后台入口独立，不沿用公开站点的 /zh/admin/ 页面。

核心流程：管理员登录 → 新增或编辑 → 上传附件 → 保存草稿 → 预览 → 发布 → 访客刷新前台查看。

本期目标：公司资质、专家团队、课程均能可靠保存、受控发布，未登录访客不能执行任何管理操作。保持现有前台视觉、路由和正常浏览体验。

## 2. 范围与约束

### 本期范围

- 本机管理员初始化、登录、退出、会话过期和接口鉴权。
- 公司资质、专家团队、课程的新增、编辑、排序、预览、发布、下架与删除。
- 图片、文档和视频的本地持久化、权限控制及异常提示。
- 草稿与公开内容隔离、前台接入、备份恢复说明、云端迁移说明。
- 中文管理界面；后台手动维护中文、英文、越南文三套内容，保留已有前台语言入口和内容展示能力，不自动翻译内容。

### 本期不包含

- 公网部署、域名购买、云服务采购。
- 公众注册、学员账号、付费购课、支付、考试和学习进度。
- 多管理员管理界面、复杂角色体系、多人审批、自动翻译。
- 视频转码、多清晰度、直播、断点续传和专用视频服务；后续按实际视频规模扩展。

### 开发约束

- 仅在独立后台分支和工作目录实施，不修改原验收分支。
- 运行端口及数据目录与其他演示实例隔离，不覆盖原项目内容。
- 不读取现有凭据，不将密码、会话或密钥写入代码、文档和版本库。
- 既有数据迁移前备份，并在隔离副本验证；不在真实内容中插入测试数据。

## 3. 用户与权限

| 身份 | 能力 |
|---|---|
| 访客 | 浏览已发布内容、查看公开图片、播放公开课程视频、下载公开资料 |
| 管理员 | 登录后管理三类内容及附件，查看草稿和预览，发布和下架 |

不开放公众注册。第一个管理员通过本机终端初始化命令创建，密码在终端隐藏输入，不提供默认通用密码。重复初始化不能覆盖既有账号；忘记密码通过本机终端重置，重置后已有会话失效。本期仅支持一个管理员。

管理员页面和全部管理接口均验证身份；隐藏链接不能代替鉴权。未登录请求不得返回管理数据或草稿。

## 4. 页面与入口

- 前台保留现有公开展示网址；新后台使用独立网址，不沿用 /zh/admin/。后台根路径未登录时进入登录页。
- 未登录访问管理页跳转登录；登录成功进入管理首页。
- 管理首页显示三个栏目、内容数量及待发布草稿数量。
- 管理区持续显示当前账号、查看前台及退出按钮。
- 云端使用独立后台地址，例如 https://admin.example.com；前台例如 https://www.example.com。两个入口分别配置路由，公开前台不提供管理页面或管理接口，旧 /zh/admin/ 及其他语言管理入口不再提供管理功能。独立网址之外仍必须进行服务端鉴权；上线前配置 HTTPS。
- 本地通过不同端口提供两个网址，例如前台 http://127.0.0.1:4180、后台 http://127.0.0.1:4181（端口仅为示例，实施时检查占用）。管理员只需打开后台网址即可登录和管理，无需从前台进入。实际地址写入启动说明，不复用其他运行实例端口。
- 后台使用受保护的管理接口保存及发布内容；前台只读取已发布内容。可共用代码模块、数据库和文件存储，但按两个监听入口分别限制可访问路由。
- 本地两个端口使用同一主机名时 Cookie 不按端口隔离，实施时须使用后台专属会话 Cookie、严格请求来源校验及 CSRF 防护；生产后台会话使用仅后台主机有效的 Cookie，不向整个父域共享。

## 5. 内容管理

### 5.1 通用操作

列表提供搜索、状态筛选、排序及新增入口；每条记录可编辑、预览、发布和下架。列表明确标注草稿、已发布、已下架以及是否有未发布修改。上传与资料完善分开：管理员可以先上传图片、视频或附件再补充文字，后台按每条资料、每种语言显示“已完善”“待补充”“缺主要资料”状态。

编辑页提供保存草稿、预览、发布和返回。表单标明必填字段，错误定位到具体字段；保存失败保留输入，保存成功明确提示。离开未保存页面时提醒。重复点击提交不产生重复记录。

### 5.2 公司资质与合作资料

本节重点把控资料上传、独立记录保存、附件管理与发布校验，同时采用以下首版资料展示布局；首页三个分类入口不在本次修改范围内。

- 桌面端每条资料采用“左图右文”：左侧完整展示证书、认证图片或合作案例封面，保持原比例，不裁切、不拉伸；右侧显示名称、颁发或合作机构、时间/有效期、简短说明，以及有原件附件时才显示的“查看原件”入口。
- 每条资料独立成卡片，纵向排列；每张证书、每份认证、每个合作案例独立上传和维护，不把多份资料压成一张合集图。
- 手机端自动改为“图片在上、文字在下”，图片仍保持完整比例。
- 按实际填写内容展示字段，缺失文字不显示空标签；只有附件、没有展示图时不显示破损图片或空图片占位，可通过“查看原件”访问公开附件。

| 类型 | 每条资料可上传/填写 |
|---|---|
| 资质证书 | 证书图片、名称、颁发机构、证书编号（可选）、有效期、说明、原件附件 |
| 认证文件 | 认证图片、认证名称、认证机构、认证说明、有效期、相关附件 |
| 合作资料 | 案例封面、合作方名称或匿名名称、项目名称、合作内容、我方职责、可公开成果、相关图片或文件 |

分类在新增时选择；除分类外，上表文字字段均允许为空。管理员可只上传展示图片或附件后保存，系统不得因缺少名称、机构、有效期或说明而拒绝上传或保存草稿。有效期支持长期有效，到期展示提示，不自动宣称证书真实有效；合作案例仅填写经授权的公开信息，不填充虚构证书、认证或成果。

后台对每一条、每个语言版本进行资料完整性提示：

- **已完善**：已有展示图片或附件，且名称、机构/合作方与说明等主要资料齐全。
- **待补充**：已上传展示图片或附件，但缺少名称、机构/合作方、说明、时间或其他推荐字段；列表以醒目提示列出缺失字段。
- **缺主要资料**：既没有展示图片，也没有公开附件；提示需要补充主要资料。

发布的最低条件仅为当前语言版本至少有一张展示图片或一个公开附件。点击发布时，如仍有待补充字段，后台弹出缺失项提醒，管理员可以选择继续发布或返回补充，不强制阻止发布。前台只显示已填写字段，不显示空标签；名称未填写时仅显示该分类的通用名称（如“资质证书”），绝不展示原始上传文件名。无已发布内容时显示简洁空状态。

### 5.3 专家团队

字段：姓名、照片、职务、所属高校或机构、学历、简介、专业背景、研究方向、AI 教学/研究/实践经历、公开资料、展示顺序。

发布必填：姓名、照片、简介。其他字段按真实资料填写，空字段不显示占位虚构信息。

前台提供列表和详情；专家详情展示已发布关联课程。专家下架后从公开列表和关联区域移除，课程可以继续展示，但不输出该专家未公开的详细信息或失效链接。

### 5.4 课程

字段：名称、分类、简介、适用对象、大纲、封面、关联专家、视频、下载资料、展示顺序。

发布必填：名称、简介、封面。视频和下载资料允许为空，支持先发布课程介绍；关联专家为可选，公开展示时只显示已发布专家。

前台提供列表、详情、视频播放及资料下载。无附件时不显示无效按钮。公开视频支持范围请求和拖动播放，不承诺转码不兼容的视频格式。

### 5.5 三语言内容与媒体管理

后台界面本身使用中文，但每条公司资质、专家和课程均以一个固定内容 ID 管理中文（zh）、英文（en）和越南文（vi）三个语言版本。新增记录时先建立固定 ID，再分别录入各语言内容；不得通过翻译后的名称建立或匹配关联关系。课程与专家继续保留既有固定 ID 关联，前台沿用现有课程详情到专家详情的跳转逻辑。

**按语言独立维护的字段**：名称、分类、简介、适用对象、课程目标、大纲、讲师职务、机构、学历、专业背景、研究方向、AI 经历、资质说明、签发机构、有效期展示文案、视频片段标题、下载资料的展示名称和其他访客可见文字。

**跨语言共用的管理字段**：固定内容 ID、排序、上架状态、课程与专家关联和文件内部编号。关联课程、关联专家一律保存固定 ID；前台按当前语言读取对方的对应语言显示名称与详情。

**按语言单独上传的访客可见媒体**：课程封面、专家照片、资质展示图、视频封面、视频源文件、下载资料和其他公开附件均在中文、英文、越南文标签下分别上传和保存。即使文件内容相同，也不自动共用或回退到其他语言版本。后台为每种语言显示独立的媒体槽位和预览，不以 CSS、OCR 或机器翻译替换图片中的文字。视频含口播、字幕或画面文字时，应上传对应语言的视频版本；系统不自动生成字幕、配音或翻译版本。

课程学习预览片段不设数量上限，各语言版本可新增、编辑、删除和排序多个片段；每个片段包含标题、视频文件和视频封面。视频统一要求 MP4、H.264 视频编码、AAC 音频、16:9 画面，建议 1280×720 或 1920×1080，目标压缩后约 20MB，单文件服务端上限建议 30MB。视频封面也使用 16:9。前台预览卡片固定 16:9，视频和封面按完整画面铺满卡片；后台对非 16:9 文件明确提示或阻止发布，避免黑边、拉伸或裁切。

编辑页包含“基础设置”以及“中文 / English / Tiếng Việt”语言标签。基础设置仅维护固定 ID、排序、发布状态和课程—专家关联；每个语言标签维护该语言全部访客可见文字和媒体：

- 切换标签只读取和保存该范围字段；语言 A 保存不得清空、复制、引用或覆盖语言 B 的文字和媒体。
- 切换时存在未保存输入必须提示保存、放弃或取消切换。
- 列表和编辑页显示三种语言各自的已录入、未录入、待完善和缺少媒体状态；不要求三种语言同时完成。
- 新上传媒体仅绑定当前选择的语言区；替换、删除或下架时显示其被哪些语言版本引用，避免误删其他语言正在使用的文件。
- 不允许以“缺少翻译时自动显示中文”作为公开默认行为。某语言没有录入某条课程、专家或资质时，该语言前台对应栏目不展示该条内容；该语言没有任何已录入内容时，栏目显示简洁空状态。
- 课程关联的专家在当前语言没有录入或未上架时，课程仍可按现有前台逻辑展示，但不输出指向该专家的失效链接；专家在其已录入语言中继续展示其关联课程。

## 6. 草稿与发布规则

- 新增记录保存后默认为草稿，公开页面及接口均不可读取。
- 点击发布前验证必填字段与附件完整性；成功后前台下一次刷新展示最新内容，无需修改前台代码或重新构建。
- 发布沿用一条内容的现有保存、预览、发布和下架操作，不增加“发布当前语言”或“全部语言发布”按钮，也不要求三种语言内容齐全。逐一验证已录入语言版本：资质与合作资料至少有一张展示图片或一个公开附件即可发布，推荐文字字段缺失时列出提示并允许继续；专家必须具备姓名、照片、简介；课程必须具备名称、简介、封面。专家和课程不适用仅上传附件即可发布的宽松规则。未录入语言不会阻止发布，并在该语言前台显示为空。
- 编辑已发布内容时保存为待发布修改，前台继续展示上次已发布版本；再次发布才替换公开版本。
- 预览仅管理员可访问，并明确标注预览状态。
- 下架后从公开列表、详情及内容接口移除；内容独占的附件也不可通过旧链接直接访问。
- 同一文件被其他已发布内容引用时仍可公开访问；后台显示引用关系，避免误删。
- 删除需二次确认，已发布内容先下架；删除失败时保留原内容。附件清理不得影响其他内容或待发布版本。
- 同时打开多个编辑窗口时检测版本冲突，提示重新加载，避免静默覆盖。

## 7. 上传与文件管理

- 图片默认支持 JPG、PNG、WebP，单文件上限建议 10MB。
- 文档默认支持 PDF、DOCX、XLSX、PPTX，单文件上限建议 30MB。
- 视频本期仅支持浏览器常见 MP4，要求 H.264 视频编码、AAC 音频与 16:9 画面；目标压缩后约 20MB，单文件上限建议 30MB。实际编码兼容性以浏览器播放验收为准。
- 上述限制集中配置，界面明确提示；实施时根据本机及目标服务器能力核对。
- 服务端校验扩展名、文件类型及可识别的文件特征，拒绝可执行文件、HTML 和超限文件。
- 原始文件名仅用于显示，磁盘文件采用独立编号，防止同名覆盖和路径穿越。
- 显示上传进度、成功或失败原因；失败可重新上传，已填写表单保留。
- 文件保存成功且元数据提交成功后才提示保存完成；中断上传不得发布损坏文件，临时文件定期清理。
- 替换附件时保留旧公开版本所需文件，直到新版本发布成功；保留/移除附件操作明确可见。
- 文件经过受控接口访问；草稿附件不能通过静态目录绕过权限。下载文档使用附件响应，图片和视频按正确类型输出。
- 已被访客下载的文件副本不在下架回收范围内。

## 8. 登录与服务端安全要求

- 密码使用成熟的带盐密码哈希算法保存，不存明文、不记录密码日志。
- 使用服务端可撤销会话；浏览器 Cookie 设置 HttpOnly、SameSite，生产 HTTPS 设置 Secure。
- 会话空闲过期建议 30 分钟，最长有效期建议 8 小时；过期提示重新登录，敏感写操作不继续执行。
- 退出和密码重置使对应会话失效。
- 登录失败统一提示，增加请求限速和暂时冷却，避免暴力尝试。
- 所有写操作防跨站请求伪造；不以页面状态或浏览器传入的管理员标记作为授权依据。
- 数据目录、账号数据、备份、服务源码及配置不得通过网站直接访问。
- 对标题、简介和文件名等输入校验并安全输出，防止脚本注入。

## 9. 数据、备份与迁移

现有演示使用本地 JSON。新管理内容及账号会话优先使用 SQLite 事务保存；文件保存于独立持久化目录。最终数据库实现如需调整，应保持本 PRD 的发布一致性和恢复要求。

从原内容导入时保留既有上架状态、字段、排序、关联关系、附件及已有 `zh / en / vi` 翻译。迁移可重复执行且不重复生成记录。导入前对每条内容生成语言完整性报告；未提供某语言的字段、图片、视频或附件标记为未录入，该语言前台不展示该条内容，不以中文值、中文媒体或伪造翻译填充。原始数据保留备份，不静默改写原验收目录。

提供备份及恢复命令或明确操作说明，覆盖数据库、上传文件和必要配置，使用一致性快照，避免数据库与文件版本错位。备份不进入公开目录。

未来云端迁移包含代码、数据库、文件和配置；使用相对资源路径及可配置基础地址，避免写死本机盘符。上线需另行设置生产管理员凭据、HTTPS、持久化存储及定期备份。部署迁移不属于本期执行范围。

## 10. 异常与反馈

| 场景 | 预期行为 |
|---|---|
| 账号密码错误 | 明确提示登录失败，不泄露账号是否存在 |
| 未登录调用管理接口 | 返回未授权结果，不读取或修改数据 |
| 会话过期 | 提示重新登录，不误报保存成功 |
| 文件过大或类型不支持 | 给出实际限制，不丢失其他表单输入 |
| 上传中断或磁盘空间不足 | 操作失败并说明原因，不破坏已发布版本 |
| 发布缺少必填项 | 专家、课程按各自必填项阻止发布并定位问题；资质与合作资料缺展示图片及公开附件时阻止发布，仅缺推荐文字时提醒并允许继续 |
| 内容或附件已下架 | 公开访问不可读取，提供合理返回入口 |
| 无已发布内容 | 展示空状态，不使用虚构数据补位 |

## 11. 验收标准

1. 新环境可在终端创建管理员；无公开注册接口，未初始化前不能通过默认账号进入。
2. 正确账号可登录；错误密码被拒绝；退出、过期及重置后旧会话失效。
3. 未登录直接访问管理页面、管理接口、上传接口、草稿详情及草稿文件均不能获取受保护内容或执行修改。
4. 三类内容分别完成新增、实际上传、保存草稿、预览、发布；草稿不公开，发布后刷新前台可见。
5. 已发布内容保存修改后，前台仍显示旧版本；再次发布才显示新版本；失败不破坏旧版本。
6. 三类内容均可修改排序和下架；公开详情及独占附件旧链接不能绕过下架规则。
7. 视频可播放并拖动，图片可显示，文档可下载；无附件时不出现失效按钮。
8. 超限文件、错误类型、上传中断和重复提交得到正确处理，不产生重复内容或损坏公开文件。
9. 专家与课程关联、附件替换和删除不会留下公开失效链接或误删共享文件。
10. 重启后账号、内容、状态及附件保留；备份在独立目录恢复后，三类内容及文件可正常读取。
11. 桌面和手机前台展示正常，后台基本表单可用，既有公开页面和语言入口无回归。
12. 使用独立测试数据运行验收，不更改原验收分支、原运行实例或真实内容。
13. 前后台使用两个独立网址；后台根地址进入登录，前台域名或端口无法提供管理页面和管理接口，旧三语管理路径不可绕过新入口；管理员登录后台并发布后，前台刷新显示更新。
14. 管理员分别编辑中文、英文、越南文的同一课程、专家和资质后，保存任一语言不会修改、引用或覆盖另外两种语言的文字、图片、视频、附件或发布版本；未保存切换语言会得到明确提示。
15. 三种语言分别上传课程封面、专家照片、资质展示图、视频封面、视频文件和公开附件。前台切换语言后只读取对应媒体；缺少该语言媒体时不回退到其他语言媒体。
16. 学习预览片段不设数量上限，验证每种语言可添加超过 3 个片段并独立编辑、删除、排序和保存；视频及封面均为 16:9，后台对格式、编码、尺寸和大小给出校验提示，前台视频完整铺满 16:9 卡片，不出现拉伸、黑边或裁切。
17. 课程与专家关联仅按固定 ID 保存，保留现有前台跳转逻辑。目标专家的当前语言不存在或未上架时，不输出失效链接，也不回退到错误语言。
18. 仅录入中文时，英文和越南文前台课程、专家、资质栏目为空；补录某语言后只在该语言前台显示，不影响其他语言已发布内容。
19. 资质证书、认证文件和合作资料可逐条独立上传、保存、替换附件和发布；首版展示采用独立卡片纵向排列，桌面端左图右文，手机端图上文下。图片保持原比例、完整展示、不裁切、不拉伸，不使用多份资料合集图；有原件附件时显示“查看原件”，无展示图时不出现破损或空图片占位。首页分类入口不在本次修改范围内。
20. 管理员可先上传图片或附件并保存草稿。后台按每条资料和每种语言提示完整性并列出缺失字段；仅资质与合作资料允许只有图片或公开附件时继续发布，不强制填写名称、机构、说明或时间。专家缺姓名、照片或简介，课程缺名称、简介或封面时必须阻止发布。
21. 前台只显示已填写字段；未填写名称时使用分类通用名称，不展示原始文件名或空字段标签。

## 12. 实施顺序与交付物

5. 执行上述验收，交付本地启动、账号初始化、备份恢复及未来云端迁移说明。
