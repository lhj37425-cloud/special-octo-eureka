## 三条硬规则

1. **先校验再解包**：`sha256sum -c SHA256SUMS`，两个包都 OK 才继续。
2. **先读回滚再部署**：知道停服务、恢复数据、恢复 Nginx 配置的命令。
3. **任何不一致就停**：SHA256、数据数字、tag、端口、DNS、证书、旧站，任何一项对不上都先问交付人，不要凭经验绕过。

## 包内结构

```text
evol-app-v1.0-deploy.tar.gz   # 代码（不含 data/node_modules）
evol-data-v1.0-deploy.tar.gz  # 数据（state.json、留言、上传文件；含真实数据，走加密渠道）
SHA256SUMS                    # 两个包的校验和
README.md                     # 本文件
部署/                         # 手册、事实文件、预检/验证脚本、AI 清单
```

## 不要做

- 不要先看业务代码；
- 不要把 `data/` 提到 git 或公开仓库；
- 不要手改 `state.json`；
- 不要把 4173/4181 绑定到 `0.0.0.0`；
- 不要跳过 S03 预检和 S10 上线后验证；
- 不要在正式数据上跑测试；
- 不要在上线窗口改代码，只部署 tag 对应的包。
