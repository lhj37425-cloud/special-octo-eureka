# EVOL DREAM 官网演示 MVP

本地可演示版本。沿用 2026-10-17 官网公开页面、三语路径、图片、样式及原始交互脚本，新增 AI课程、师资展示、内容管理。无需 npm 安装依赖，使用本机 Node.js。

## 开始演示

1. 双击 `D:\项目\Start-MVP.cmd`，保留打开的终端窗口。
2. 浏览器打开 **http://127.0.0.1:4173/zh/**。
3. 后台打开 **http://127.0.0.1:4173/zh/admin/**，也可从页脚“内容管理”进入。
4. 如果端口已被占用，先关闭之前的演示服务窗口，再启动。不要同时运行旧版服务器。

也可在 PowerShell 的 `D:\项目` 目录输入 `node server.js`。不要直接双击 HTML，也不要用 Python 静态服务器，否则无法上传、保存或提交咨询。根地址 `/` 与线上一致进入越南语；中文演示请直接打开 `/zh/`。

## 推荐演示顺序

- 首页服务卡片 → 培训/Agent/项目实施；应用场景筛选 → 详情 → 预选服务的咨询页；切换语言、展开 FAQ、缩窄窗口检查移动菜单。
- 后台“师资管理” → 新增师资，填写姓名、职务、简介、专业方向，上传照片与资料，保存。
- 后台“课程管理” → 新增课程，填写名称、分类、简介、适用对象和大纲，关联讲师，上传封面、视频和课件，保存并上架。
- 前台“AI课程” → 课程详情 → 播放视频/下载资料 → 点击讲师 → 师资详情及关联课程。
- 返回后台编辑资料、下架课程，刷新前台确认消失；再上架恢复。直接访问下架详情会给出返回入口。
- 咨询表单填写演示信息、同意隐私后提交，可显示本地记录及确认页。此版本**只保存在本机，不发真实邮件**。
- 关闭服务再启动，确认课程、师资与上传文件仍保留。

## 与官网的对应关系

- 官网 17 个常规页面 × 中/越/英三语，以及三语确认页均保留；原有公开跳转使用相同路径与参数，不替换成 Hash 或提示弹窗。
- 原有场景筛选、FAQ、语言 query/hash 保留、移动菜单及表单前端校验、12秒超时/重试逻辑使用原始脚本。
- 增加 `/zh/courses/`、`/zh/teachers/`、`/zh/admin/` 及详情；越南语和英语对应路径也可打开。新增内容的名称/简介按后台录入原文展示，不自动翻译。
- 增加课程封面、视频、课件；师资照片、简介、专业方向、相关资料及课程关联。上传是真实本地文件保存，不使用刷新后失效的 blob URL。
- 咨询后端是本地替代实现，不连接官网服务或邮件队列。原始官网中的公司介绍/政策说明仅用于页面演示，不代表本地版本已经部署其线上服务。
- 后台是单人本地演示，无登录与权限系统，服务仅监听 127.0.0.1。此次未建设正式云存储、转码、生产认证或部署。

## 文件与数据

- `public/`：原始页面、样式、交互脚本及公开图片；`public/admin.js` 与 `public/mvp.css` 为新增内容管理与样式。
- `server.js`、`views.cjs`：本地服务及课程/师资/管理页面。
- `seed.json`：初始虚拟课程和讲师。
- `data/mvp-content.json`：课程与师资，首次启动优先迁移原 `data/db.json` 的课程与师资字段。原数据库不被覆盖，也不读取其中的咨询内容用于展示。
- `data/mvp-uploads/`：持久化图片、视频、资料；资料下载采用随机文件名。单文件限70MB，演示视频建议选短片。
- `data/mvp-leads.json`：本地咨询；同 requestId 重试复用记录。
- 原 `index.html/app.js/styles.css` 和 assets 保留在项目内；新服务以 public 页面为准。修改前的服务与文件备份见 `.mvp-backups/`。
