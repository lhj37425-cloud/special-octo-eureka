# 管理后台界面 Demo

本 Demo 根据 PRD v1.6 制作，仅用于评审界面及操作流程。所有公司、人物、资质与课程示例均为模拟内容。

## 启动

在此目录双击 `Start-Demo.cmd`，保留终端窗口；或运行 `node serve.cjs`。

- 后台：http://127.0.0.1:4187
- 前台模拟页：http://127.0.0.1:4186
- 演示账号：`demo-admin`
- 演示密码：`demo1234`

登录页已预填演示账号。不要输入真实账号密码。两个地址仅在本机可访问，不能双击 HTML 文件直接运行。

## 推荐体验

1. 登录后查看总览，进入“资质与合作资料”。编辑“待补充”的模拟认证，体验完整度提示。
2. 新增资料，在基础设置选择类型；切换中文标签，先选择图片或 PDF，保存草稿，再预览。
3. 不填写名称、机构和说明直接发布，查看缺失字段提醒，选择“仍然发布”。
4. 打开前台模拟页查看，名称为空时显示资料类别，不暴露原始文件名。
5. 修改已发布内容，保存草稿：预览显示修改，前台仍显示旧版；再次发布后前台才更新。
6. 切换 English 或 Tiếng Việt，分别填写和上传；没有录入的语言在前台保持为空。
7. 进入专家或课程编辑，删除必填项并尝试发布，查看校验提示。
8. 课程编辑支持不限数量的片段，包含标题、视频及封面，支持上移、下移和删除。添加空片段会阻止发布，删除空片段后可继续。
9. 勾选“演示下一次上传失败”后选文件，体验失败提示，再次选择即可重试。
10. 在列表下架或删除模拟内容；顶部“重置演示数据”可以恢复初始样例。

## 模拟范围

- 登录仅用浏览器会话模拟，不具有真实身份认证或权限保护。
- 内容与所选文件通过 IndexedDB 保存在当前浏览器的本地存储中，不上传到服务器、不写项目数据库。更换浏览器或端口不会带走这些数据。
- 静态服务只提供 Demo 文件，没有账号、上传或内容管理 API。前台通过浏览器消息读取同一个模拟数据源，没有接入原官网。
- 文件格式、大小和媒体尺寸只在浏览器中校验；不验证 MP4 内部 H.264 / AAC 编码，不模拟真实服务器安全、网络容错或断点续传。
- 同一浏览器内，前台自动检查发布更新，也可点击“刷新内容”。不同浏览器和设备不会同步。
- 本机存储仍受浏览器配额限制，建议用短片体验视频流程。原项目数据和其他运行实例不受影响。
- 本 Demo 未实现账号初始化、密码重置、真实鉴权、备份恢复或数据迁移；这些属于正式开发阶段。

## 文件

- `index.html`、`demo.css`、`demo.js`：界面与交互。
- `store.js`：模拟内容与浏览器本地保存。
- `bridge.html`：前后台模拟页之间的浏览器消息同步。
- `serve.cjs`：仅限本机的两个静态文件入口。

不需要安装 npm 依赖。关闭启动终端或按 Ctrl+C 停止服务。若提示端口占用，请关闭已运行的本 Demo 实例，不要停止其他项目。
