# 改版工具

改版 v2 期间用的辅助脚本，不是网站代码。浏览器用本机 Chrome，Playwright 装在 `D:\项目\node_modules`（脚本里按绝对路径加载）。

| 文件 | 做什么 | 怎么用 |
|---|---|---|
| `启动预览站.cmd` | 启动改版预览站（只开前台）：http://127.0.0.1:4273/zh/ 。代码用改版文件夹 `D:\项目-改版`，数据读 `D:\data网站数据保存\预览数据\` 里的副本 | 双击；关掉弹出的窗口就停了 |
| `preview-server.cjs` | 预览站的实际启动脚本：先设好 `PORT`、`MVP_DATA_DIR`、`ADMIN_DATA_DIR` 再加载 `server.js`；数据目录指向 `D:\项目\data` 时拒绝启动 | `node preview-server.cjs` |
| `检查网站.cjs` | 查真网站：区块是否超一屏（1366 / 1440 / 1920；课程页、专家页必须一屏，隐私、条款不要求，其他页面尽量一屏、超了只提示；第一块深色首屏伸到页头后面时按整个屏幕高算）、手机 390 是否横向溢出、坏图和失败请求、文字对比度、小于 12px 的字、英越页面混进中文、脚本报错；可同时拍整页截图。页面从三种语言首页顺着链接自动找全 | `node 检查网站.cjs --shots 截图目录`（默认查 4273；`--lang zh`、`--only courses` 缩小范围；`--report 文件` 指定报告位置） |
| `静态页加样式表.cjs` | 给 `public/{zh,vi,en}` 下全部 27 个静态页加一个样式表链接（放在 `</head>` 前），已经有的跳过 | `MSYS_NO_PATHCONV=1 node 静态页加样式表.cjs /v2.css`（在 Git Bash 里不加前面那句，`/v2.css` 会被改写成 `C:/Program Files/Git/v2.css`；PowerShell 里不用加） |
| `页头语言平铺.cjs` | 全站页头照豆包（2026-10-28）：把 27 个静态页的语言下拉换成平铺的“中文 &#124; VI &#124; EN”，并在 `</head>` 前加页头脚本 `/v2.js`；已经换过的跳过。课程、专家、案例页和 404 用静态页作外框，会跟着变 | `node 页头语言平铺.cjs` |
| `换品牌标志.cjs` | 换成甲方给的 logo（2026-10-28，原图和去白底后的图在 `D:data网站数据保存甲方logo-2026-10-28`）：27 个静态页页头、页脚的旧图标换成 `/brand/evol-mark.png`，补上 PNG 网页图标和苹果主屏幕图标；已经换过的跳过。`/favicon.svg` 里放的是 64×64 的新图标（后台也读这个文件） | `node 换品牌标志.cjs` |
| `生成对比页.cjs` | 把改版前、改版后两套整页截图并排放进一个网页，逐页对照 | `node 生成对比页.cjs 改版前截图目录 改版后截图目录` |
| `生成宋体网页字体.cjs` + `裁剪宋体.py` | 从预览站三种语言的全部页面收集用宋体显示的字（标题等），加上英文、越南语字母和标点，从本机的 `C:\Windows\Fonts\NotoSerifSC-VF.ttf` 裁出来，固定为粗体，存成 `public/fonts/evol-serif-700.woff2`。字表留在 `输出/宋体字表.txt` | 先开预览站，再 `node 生成宋体网页字体.cjs`。标题文案、课程名、专家名改了要重新运行并提交新字体；需要 `python -m pip install fonttools brotli`（2026-10-27 已装） |
| `概念稿脚本/` | 概念稿 v2 用过的检查和截图脚本。页面路径已改到 `D:\data网站数据保存\改版概念稿v2-2026-10-27\网页`，截图输出到 `概念稿脚本/输出/` | `node 概念稿脚本/check-concept.cjs` |

- 改版前截图和检查结果：`D:\data网站数据保存\改版前截图-2026-10-27\`（`电脑版/` 1366 宽整页、`手机版/` 390 宽整页、`检查结果.md`）。文件名里的编号三种语言一致，比如 `zh-01-首页.jpg` 和 `vi-01-首页.jpg` 是同一页。
- 后台暂缓（2026-10-27），预览站不开后台。
